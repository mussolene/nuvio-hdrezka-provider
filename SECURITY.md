# Безопасность

## Хранение данных

Провайдер не содержит встроенных учетных данных и не отправляет телеметрию.
Логин и пароль используются только для запроса входа и не сохраняются. После
успешного входа файлы cookie сеанса шифруются ключом Android Keystore и хранятся
в закрытом хранилище приложения Nuvio.

В журнал попадают только результат проверки сеанса и имена полученных файлов
cookie. Их значения, логин и пароль не записываются.

Сеанс привязан к основному домену. При смене домена требуется новый вход.
Файлы cookie учетной записи не передаются сторонним видеосерверам.
Проверка сертификатов и имени сервера HTTPS остается включенной.

## Сообщение об уязвимости

Не публикуйте учетные данные, файлы cookie и другие секреты в открытой задаче.
Используйте раздел Security репозитория и создайте приватное сообщение об
уязвимости. Укажите версию провайдера, версию Android, шаги воспроизведения и
журнал без персональных данных.

## Границы поддержки

Поддерживается только код этого репозитория. Работа внешнего сайта, его
содержимое, учетные записи и сетевые ограничения находятся вне проекта.
