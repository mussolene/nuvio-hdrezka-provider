# HDRezka для Nuvio

[![Проверка сборки](https://github.com/mussolene/nuvio-hdrezka-provider/actions/workflows/build.yml/badge.svg)](https://github.com/mussolene/nuvio-hdrezka-provider/actions/workflows/build.yml)
[![Лицензия GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)

Изолированный CloudStream-провайдер HDRezka для Nuvio на Android TV. Он добавляет
поиск, карточки фильмов и сериалов, сезоны, серии, озвучки, субтитры и доступные
варианты качества, включая 1080p, когда такое качество предоставляет источник.

В проекте нет телеметрии, рекламы, пожертвований и общего каталога сторонних
расширений. Провайдер не связан с Nuvio или владельцами внешнего сайта.

## Установка

1. Откройте в Nuvio раздел `Настройки -> Контент и поиск -> Плагины`.
2. Добавьте адрес репозитория:

   ```text
   https://raw.githubusercontent.com/mussolene/nuvio-hdrezka-provider/main/dist/repository.json
   ```

3. Обновите репозиторий и включите провайдер HDRezka.

После установки постоянно работающий компьютер или отдельный сервер не нужен.
Nuvio загружает готовый пакет напрямую из GitHub.

## Вход в учетную запись

Основной домен: `rezka.fi`. На этом зеркале для просмотра требуется вход.
При первом запуске провайдер предлагает авторизацию и сохраняет сеанс.
Озвучки Premium отображаются только при наличии соответствующей подписки сайта.

Выбор "Без входа" сохраняется после перезапуска. Сетевые ошибки не удаляют
сохраненный сеанс и не вызывают повторное окно входа. Ручной вход доступен через
стандартные настройки расширения в клиентах, которые поддерживают эту кнопку.
Текущая интеграция Nuvio не отображает настройки расширения.

Логин и пароль используются только в запросе входа к `rezka.fi` и не
сохраняются. Полученные файлы cookie сеанса шифруются ключом Android Keystore и
хранятся в закрытом хранилище Nuvio. Подробности описаны в [SECURITY.md](SECURITY.md).

Озвучка, качество и формат HLS или MP4 указаны в названии каждого потока.
Режиссерские версии остаются отдельными вариантами. Запросы озвучек выполняются
с ограничением в три одновременных соединения.

## Сборка и проверка

Требуются JDK 17 и доступ к репозиториям зависимостей Gradle.

```sh
./gradlew --no-daemon -Pkotlin.incremental=false \
  :HDrezkaNuvio:testDebugUnitTest \
  :HDrezkaNuvio:make
```

Готовый пакет появится в `dist/HDRezkaNuvio.cs3`. GitHub Actions повторяет
проверку для каждого изменения и сохраняет пакет как артефакт сборки.

Поиск использует обычные HTTP-запросы браузера. Заголовки старого приложения
HDrezka App не отправляются: rezka.fi отклоняет их сочетание с HTTP 403.

## Ограничения

- Доступность поиска и потоков зависит от внешнего сайта и текущей сети.
- Каталог, русские названия и постеры Nuvio зависят от доступности TMDB.
- Изменение разметки или интерфейса внешнего сайта может потребовать обновления.
- Пользователь самостоятельно отвечает за соблюдение правил сервиса и местного
  законодательства.
